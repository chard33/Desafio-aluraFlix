
# Aluraflix

Aluraflix es una plataforma diseñada para gestionar videos, con funcionalidades como listar, registrar, actualizar y eliminar videos. Este proyecto fue desarrollado como parte del challenge de la formación del Programa ONE, una alianza entre Alura Latam y Oracle.


## Tecnologías Utilizadas

### Frontend

**Vite**: Herramienta de desarrollo rápida para aplicaciones modernas.

**React**: Biblioteca para construir interfaces de usuario basadas en componentes reutilizables.

**Componentes React**: División del código en pequeñas piezas modulares y reutilizables.

**CSS Modules**: Estilizado aïslado para evitar conflictos entre clases.

[![Vercel](https://img.shields.io/badge/vercel-%23000000.svg?style=for-the-badge&logo=vercel&logoColor=white)](https://desafio-alura-flix-iota.vercel.app/NVideo)

### Backend

**FakeAPI**: Simulación de una API REST para manejar las operaciones CRUD (Create, Read, Update, Delete) de los videos.

[![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/chard33/FakeApiAFlix)

## Funcionalidades

Listar Videos: Muestra un listado completo de los videos registrados en la plataforma.

Registrar Videos: Permite agregar nuevos videos proporcionando detalles como título, descripción y URL.

Actualizar Videos: Modifica la información de videos existentes.

Eliminar Videos: Elimina videos de la base de datos simulada.

Diseño Responsive: Adaptado para una experiencia óptima en dispositivos móviles y de escritorio.
